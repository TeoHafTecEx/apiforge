Connect to your GitHub repo

Builds run as GitHub Actions in your repo. This page needs a token to start them and read the results. It stays in this browser.

How to create the token
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Choose Generate new token. Under Repository access, pick Only select repositories and select this repo.
  3. Under Repository permissions, set Actions to Read and write, and Contents to Read-only.
  4. Generate it and paste it here.
